# OneClient Bedwars 1.8.9 profile on CachyOS

This repository is a **visual-only setup guide and human-readable template** for a separate Minecraft 1.8.9 Bedwars instance on CachyOS. It does not contain OneClient source, a custom Minecraft client, mod binaries, or an installer. OneClient does not directly import the YAML in `config/`.

## Recommended product

A clean 1.8.9 OneClient instance with Java 8 selected where supported, followed by optional visual/HUD additions only after checking exact version, loader, dependencies, official source, behavior, and the target server's rules. The default is vanilla Clean Bedwars; test it before adding anything.

## OneClient release

Use the [OneClient 2.10.2 release](https://github.com/Polyfrost/OneLauncher/releases/tag/oneclient-2.10.2) or [latest official release](https://github.com/Polyfrost/OneLauncher/releases/latest) and select the asset matching your architecture. This repo does not guarantee that a specific legacy loader/OptiFine combination is supported; test vanilla 1.8.9 first and keep its logs.

## Safety

No autoclickers, aim assistance, reach changes, ESP/wallhacks, automated combat/bridging, packet manipulation, or anti-cheat bypasses. Client-side does not automatically mean server-permitted; check the rules for the specific server.
