# OneClient Bedwars 1.8.9 profile on CachyOS

A visual-only setup guide for a separate Minecraft 1.8.9 Bedwars instance. Start vanilla, select Java 8 explicitly, and add individually verified mods only when the target server permits them. No mod binaries or custom client are bundled here.

## Official launcher

Get OneClient from the [official OneLauncher releases](https://github.com/Polyfrost/OneLauncher/releases/latest). Choose the Linux package matching your architecture. This project is a configuration/documentation template; it is not OneClient source code and does not provide an importable OneClient profile.

## Safety

This profile excludes autoclickers, aim assistance, reach modifications, ESP/wallhacks, automated combat/bridging, packet manipulation, and anti-cheat bypasses. Confirm the rules of the specific Bedwars server before using any third-party mod.
