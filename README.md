# OneClient Bedwars 1.8.9 profile on CachyOS

A visual-only setup guide for a separate Minecraft 1.8.9 Bedwars instance. Start vanilla, select Java 8 for the instance, and only add individually verified mods when the target server permits them. No Minecraft client, mod binaries, or installer is included.

## Official launcher

Use the [OneClient 2.10.2 release](https://github.com/Polyfrost/OneLauncher/releases/tag/oneclient-2.10.2) or [latest official release](https://github.com/Polyfrost/OneLauncher/releases/latest), and select an asset matching your system architecture. This repository is a documentation/configuration template; it is not OneClient source code and OneClient does not directly import the YAML in `config/`.

## Safety

This profile excludes autoclickers, aim assistance, reach changes, ESP/wallhacks, automated combat/bridging, packet manipulation, and anti-cheat bypasses. Confirm rules for the specific Bedwars server before using any third-party mod.
