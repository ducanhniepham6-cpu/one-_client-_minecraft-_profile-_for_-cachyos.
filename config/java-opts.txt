# Conservative Java options for Minecraft 1.8.9

Start with the launcher's default JVM arguments. If you need a small, testable baseline, add only:

```text
-Xms1G
-Xmx3G
-XX:+UseG1GC
```

Use a maximum heap appropriate for the machine; 2–3 GiB is a starting point, not a guaranteed optimum. Leave room for CachyOS, the desktop, and other applications. If startup or frame pacing becomes worse, remove custom options and compare against defaults.

Do not paste long flag bundles from generic optimization guides without checking that the selected Java 8 runtime supports them. Avoid forcing Java2D/headless/OpenGL properties or setting a fixed young-generation size for this profile without a measured reason.
